# taskie settings for this repo

verify: just verify
setup: none

This repo is taskie itself. Every pull request that changes what the plugin
does (skills, `shared/conventions.md`, `backends/`, manifests) bumps
`version` in `.claude-plugin/plugin.json`: patch for fixes, minor for new
behavior. Installed copies, including the one this repo loads on itself,
update only when the version changes. Changes to docs alone do not bump it.
